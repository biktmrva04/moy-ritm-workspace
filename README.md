# Мой ритм — облачная версия (подготовка)

Сохранен интерфейс версии 4.0; добавлены вход/регистрация через Supabase Auth и синхронизация пользовательского состояния в PostgreSQL.

## Настройка
1. Supabase-проект `moy-ritm` уже создан: `jtoymudwurammuixqscp`.
2. SQL-схема уже применена, RLS включен и политики проверены.
3. `config.js` уже содержит URL Supabase и публичный publishable key. `service_role`/secret в браузер не добавлять.
4. В Supabase Authentication -> URL Configuration добавить URL сайта Vercel как Site URL и разрешенный Redirect URL.
5. Опубликовать файлы на Vercel (это статический сайт, сборка не требуется), отдельно связать с новым GitHub-репозиторием для автоматических публикаций.
6. Открыть сайт по HTTPS, создать аккаунт, подтвердить email (если включено), войти.
7. Сначала сохранить резервную копию старых задач. Кнопка «Импорт локальных задач» появится после входа.

## Важно
- Пока Supabase не настроен, вход не работает; это штатная блокировка до подключения.
- В новой базе нет демонстрационных задач, они не загружаются в чужой аккаунт.
- Полное состояние хранится в одной JSONB-записи пользователя. При одновременных правках с нескольких устройств возможна перезапись последнего сохраненного состояния — для совместной многопользовательской работы потребуется построчная модель.
- При отсутствии сети изменения остаются в оперативном состоянии страницы, но повторное сохранение в облако нужно проверить по индикатору. Экспортируй резервную копию перед закрытием браузера, если облако недоступно.
- URL Supabase и publishable key публичны по определению. Безопасность данных обеспечивают RLS-политики.
